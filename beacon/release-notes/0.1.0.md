# Beacon .NET 0.1.0

The first usable Beacon .NET release, based on OpenTelemetry .NET Automatic
Instrumentation `v1.17.0`.

## Supported Scope

- Linux glibc x64
- .NET 8 applications
- Generic ZIP deployment
- OTLP trace, metric, and log export

## Installation

Download `beacon-dotnet-auto-0.1.0-linux-glibc-x64.zip` and its corresponding
`.sha256` file. Verify and extract the archive, then run:

```bash
sha256sum --check beacon-dotnet-auto-0.1.0-linux-glibc-x64.zip.sha256
export OTEL_DOTNET_AUTO_HOME=/absolute/path/to/beacon-dotnet-auto
export OTEL_SERVICE_NAME=my-service
export OTEL_EXPORTER_OTLP_ENDPOINT=http://datakit-host:4318
export OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf
/absolute/path/to/beacon-dotnet-auto/instrument.sh dotnet MyApplication.dll
```

## Validation

The release workflow builds the archive from pinned source, reinstalls from the
archive, and runs real .NET 8 console and ASP.NET Core applications to validate:

- OTLP trace export
- OTLP metric export
- OTLP log export
- ASP.NET Core and HttpClient trace automatic instrumentation and context
  hierarchy
- ASP.NET Core, Kestrel, and HttpClient metric automatic instrumentation
- SHA-256 integrity
- Version, source commit, and upstream-baseline metadata

## Limitations

Windows, macOS, Linux musl, ARM64, .NET Framework, NuGet deployment, and
end-to-end DataKit ingestion were not included in the verified scope of this
release.
