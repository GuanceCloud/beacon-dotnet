# Beacon .NET 0.1.0

Beacon .NET 首个可用版本，基于 OpenTelemetry .NET Automatic Instrumentation
`v1.17.0`。

## 支持范围

- Linux glibc x64
- .NET 8 应用
- 通用 ZIP 部署
- OTLP Trace、Metric、Log 导出

## 安装

下载 `beacon-dotnet-auto-0.1.0-linux-glibc-x64.zip` 及对应的 `.sha256` 文件，
校验并解压后执行：

```bash
sha256sum --check beacon-dotnet-auto-0.1.0-linux-glibc-x64.zip.sha256
export OTEL_DOTNET_AUTO_HOME=/absolute/path/to/beacon-dotnet-auto
export OTEL_SERVICE_NAME=my-service
export OTEL_EXPORTER_OTLP_ENDPOINT=http://datakit-host:4318
export OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf
/absolute/path/to/beacon-dotnet-auto/instrument.sh dotnet MyApplication.dll
```

## 验证

发布工作流从固定源码构建归档，然后从归档重新安装并运行真实 .NET 8 控制台和
ASP.NET Core 应用，验证：

- OTLP Trace 导出
- OTLP Metric 导出
- OTLP Log 导出
- ASP.NET Core 和 HttpClient Trace 自动插桩与上下文层级
- ASP.NET Core、Kestrel 和 HttpClient Metric 自动插桩
- SHA-256 完整性
- 版本、源码提交和上游基线元数据

## 限制

Windows、macOS、Linux musl、ARM64、.NET Framework、NuGet 部署模式以及
DataKit 接收链路尚未纳入本版本的已验证支持范围。
