# Beacon .NET 0.2.2

## Highlights

- Standardized Beacon product tags and GitHub Releases on the `vX.Y.Z` format.
- Restored one-command installation with assets built for the standard tag
  format.

## What's Changed

- Shell and PowerShell installers now resolve `vX.Y.Z` release URLs.
- Release metadata validation rejects the retired `beacon-vX.Y.Z` format.
- Build, publication, and post-release validation workflows now use standard
  version tags.
- Upstream-derived assembly and NuGet versioning is isolated from Beacon
  product tags, preserving runtime compatibility.
- Historical installation links now point to the renamed Releases.

## Included Packages

- Windows x64 MSI
- Debian/Ubuntu x64 and ARM64 DEB packages
- RHEL/Rocky Linux x64 and ARM64 RPM packages
- Linux glibc/musl, Windows, macOS, and NuGet ZIP archives
- SHA-256 manifest, SPDX SBOM, and GitHub artifact attestations

## Verification

Every downloadable artifact is included in `checksums.txt` and covered by a
GitHub artifact attestation. MSI, DEB, and RPM repository signing is not yet
available.
