# Beacon .NET 0.1.4

本版本保留完整跨平台资源，并完善 macOS 非特权用户的发布后验收。

## 发布内容

- Linux glibc x64、Linux glibc ARM64、Linux musl x64、Linux musl ARM64
- Windows x64/x86 组合归档
- macOS ARM64 归档
- 保留上游兼容包 ID 的 NuGet 聚合归档
- Shell 安装脚本与 PowerShell 安装模块
- SHA-256 校验清单、SPDX SBOM 和 GitHub artifact attestation

## 修复

发布后验收现在为 Unix 平台显式设置可写的
`OTEL_DOTNET_AUTO_LOG_DIRECTORY`。这使 macOS Runner 能以非特权用户启动探针，
同时保留探针既有的生产默认日志目录约定。

## 安装

```bash
curl -sSfL https://github.com/GuanceCloud/beacon-dotnet/releases/download/beacon-v0.1.4/otel-dotnet-auto-install.sh -o otel-dotnet-auto-install.sh
sh otel-dotnet-auto-install.sh
```

Windows PowerShell：

```powershell
Invoke-WebRequest https://github.com/GuanceCloud/beacon-dotnet/releases/download/beacon-v0.1.4/OpenTelemetry.DotNet.Auto.psm1 -OutFile OpenTelemetry.DotNet.Auto.psm1
Import-Module ./OpenTelemetry.DotNet.Auto.psm1
Install-OpenTelemetryCore
```

安装脚本默认使用 GitHub CLI 校验 artifact attestation。DataKit 接收链路仍需独立
端到端验收。
