# Beacon .NET 0.1.4

This release retains the complete cross-platform asset set and improves
post-release validation for unprivileged macOS users.

## Release Contents

- Linux glibc x64, Linux glibc ARM64, Linux musl x64, and Linux musl ARM64
- Combined Windows x64/x86 archive
- macOS ARM64 archive
- Aggregate NuGet archive retaining upstream-compatible package IDs
- Shell installer and PowerShell installation module
- SHA-256 manifest, SPDX SBOM, and GitHub artifact attestations

## Fix

Post-release validation now sets a writable
`OTEL_DOTNET_AUTO_LOG_DIRECTORY` explicitly on Unix platforms. This allows the
macOS runner to start the profiler as an unprivileged user while preserving the
profiler's existing production default for its log directory.

## Installation

```bash
curl -sSfL https://github.com/beacon-observability/beacon-dotnet/releases/download/v0.1.4/otel-dotnet-auto-install.sh -o otel-dotnet-auto-install.sh
sh otel-dotnet-auto-install.sh
```

Windows PowerShell:

```powershell
Invoke-WebRequest https://github.com/beacon-observability/beacon-dotnet/releases/download/v0.1.4/OpenTelemetry.DotNet.Auto.psm1 -OutFile OpenTelemetry.DotNet.Auto.psm1
Import-Module ./OpenTelemetry.DotNet.Auto.psm1
Install-OpenTelemetryCore
```

By default, the installers use GitHub CLI to verify artifact attestations.
End-to-end DataKit ingestion still requires independent validation.
