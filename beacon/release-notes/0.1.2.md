# Beacon .NET 0.1.2

This release retains the complete cross-platform asset set from `0.1.1` and
corrects the default installation-verification process.

## Release Contents

- Linux glibc x64, Linux glibc ARM64, Linux musl x64, and Linux musl ARM64
- Combined Windows x64/x86 archive
- macOS ARM64 archive
- Aggregate NuGet archive retaining upstream-compatible package IDs
- Shell installer and PowerShell installation module
- SHA-256 manifest, SPDX SBOM, and GitHub artifact attestations

Every platform archive contains `BEACON-METADATA.json`, which identifies the
Beacon version, target platform, source commit, and pinned upstream provenance.

## Installation

Linux or macOS:

```bash
curl -sSfL https://github.com/beacon-observability/beacon-dotnet/releases/download/v0.1.2/otel-dotnet-auto-install.sh -o otel-dotnet-auto-install.sh
sh otel-dotnet-auto-install.sh
```

Windows PowerShell:

```powershell
Invoke-WebRequest https://github.com/beacon-observability/beacon-dotnet/releases/download/v0.1.2/OpenTelemetry.DotNet.Auto.psm1 -OutFile OpenTelemetry.DotNet.Auto.psm1
Import-Module ./OpenTelemetry.DotNet.Auto.psm1
Install-OpenTelemetryCore
```

By default, the installers use GitHub CLI to verify that downloaded files have
artifact attestations generated by the Beacon release workflow from the exact
tag. If a repository administrator later enables Immutable Releases, GitHub
also adds Release attestations to future releases.

## Validation Scope and Limitations

Build jobs continue to validate OTLP traces, metrics, and logs with real console
and ASP.NET Core applications. After publication, the Release assets are
downloaded from their public URLs to verify installers, artifact attestations,
and metadata, and to run .NET 8 applications on Windows, macOS, and Linux
glibc/musl for x64 and ARM64.

This release does not claim Beacon-specific runtime enhancements or completed
end-to-end DataKit ingestion validation.
