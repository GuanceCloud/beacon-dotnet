# Beacon .NET 0.1.2

本版本保留 `0.1.1` 的完整跨平台资源，并修正默认安装验证流程。

## 发布内容

- Linux glibc x64、Linux glibc ARM64、Linux musl x64、Linux musl ARM64
- Windows x64/x86 组合归档
- macOS ARM64 归档
- 保留上游兼容包 ID 的 NuGet 聚合归档
- Shell 安装脚本与 PowerShell 安装模块
- SHA-256 校验清单、SPDX SBOM 和 GitHub artifact attestation

每个平台归档均包含 `BEACON-METADATA.json`，用于确认 Beacon 版本、目标平台、
源码提交和固定的上游来源。

## 安装

Linux 或 macOS：

```bash
curl -sSfL https://github.com/GuanceCloud/beacon-dotnet/releases/download/beacon-v0.1.2/otel-dotnet-auto-install.sh -o otel-dotnet-auto-install.sh
sh otel-dotnet-auto-install.sh
```

Windows PowerShell：

```powershell
Invoke-WebRequest https://github.com/GuanceCloud/beacon-dotnet/releases/download/beacon-v0.1.2/OpenTelemetry.DotNet.Auto.psm1 -OutFile OpenTelemetry.DotNet.Auto.psm1
Import-Module ./OpenTelemetry.DotNet.Auto.psm1
Install-OpenTelemetryCore
```

安装脚本默认使用 GitHub CLI 校验下载文件由 Beacon 发行工作流从精确标签生成的
artifact attestation。仓库管理员启用 Immutable Releases 后，GitHub 还会为未来
发布自动增加 Release attestation。

## 验证范围与限制

构建阶段继续验证真实控制台与 ASP.NET Core 应用的 OTLP Trace、Metric、Log。
Release 发布后还会从公开下载地址验证安装脚本、artifact attestation、元数据，
并在 Windows、macOS、Linux glibc/musl 的 x64 与 ARM64 环境运行 .NET 8 应用。

本版本未声明 Beacon 自有运行时增强，也未完成 DataKit 接收链路端到端验收。
