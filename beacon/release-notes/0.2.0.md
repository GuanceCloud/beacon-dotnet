# Beacon .NET 0.2.0

本版本新增操作系统原生安装包和统一管理命令，简化 Beacon .NET 的安装、运行状态
检查与完整卸载。

## 原生安装包

- Windows x64 MSI
- Debian/Ubuntu x64 与 ARM64 DEB
- RHEL/Rocky Linux x64 与 ARM64 RPM
- 继续提供 Linux glibc/musl、Windows、macOS 和 NuGet ZIP 归档

安装原生包后可以使用统一命令：

```text
beacon-dotnet status
beacon-dotnet version
beacon-dotnet run <command>
beacon-dotnet uninstall
```

Windows MSI 会注册安装目录和命令路径，并在卸载前清理 IIS、Windows Service 与
GAC 注册。DEB/RPM 将文件安装到 `/opt/beacon/dotnet`，并通过系统包管理器完成卸载。

## 独立安装脚本

Shell 与 PowerShell 安装方式继续保留。新安装会同时写入独立卸载入口：

- Linux/macOS：安装目录中的 `uninstall.sh`
- Windows：安装目录中的 `uninstall.ps1`

## 验证与供应链

发布工作流会构建全部归档和原生安装包，生成统一 SHA-256 清单、SPDX SBOM 与
GitHub artifact attestation。发布后会在 Windows 2022/2025、Ubuntu x64/ARM64、
Rocky Linux x64/ARM64、macOS ARM64 和 Alpine x64/ARM64 上重新下载安装，并执行
安装、运行与卸载验证。

当前 MSI、DEB 与 RPM 尚未接入 Authenticode 或软件源签名，安装前应验证 GitHub
artifact attestation。DataKit 接收链路仍需独立端到端验收。
