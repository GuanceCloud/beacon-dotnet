# Beacon .NET 0.2.0

This release adds native operating-system packages and a unified management
command, simplifying Beacon .NET installation, status checks, and complete
uninstallation.

## Native Packages

- Windows x64 MSI
- Debian/Ubuntu x64 and ARM64 DEB packages
- RHEL/Rocky Linux x64 and ARM64 RPM packages
- Continued Linux glibc/musl, Windows, macOS, and NuGet ZIP archives

After installing a native package, use the unified command:

```text
beacon-dotnet status
beacon-dotnet version
beacon-dotnet run <command>
beacon-dotnet uninstall
```

The Windows MSI registers the installation directory and command path. Before
uninstalling, it removes IIS, Windows Service, and GAC registrations. DEB/RPM
packages install files under `/opt/beacon/dotnet` and use the system package
manager for removal.

## Standalone Installers

The Shell and PowerShell installation methods remain available. New
installations also include a standalone uninstaller:

- Linux/macOS: `uninstall.sh` in the installation directory
- Windows: `uninstall.ps1` in the installation directory

## Validation and Supply Chain

The release workflow builds every archive and native package and generates a
unified SHA-256 manifest, an SPDX SBOM, and GitHub artifact attestations. After
publication, assets are downloaded and used to validate installation, runtime,
and removal on Windows 2022/2025, Ubuntu x64/ARM64, Rocky Linux x64/ARM64, macOS
ARM64, and Alpine x64/ARM64.

The MSI, DEB, and RPM files are not yet covered by Authenticode or repository
signing. Verify the GitHub artifact attestation before installation. End-to-end
DataKit ingestion still requires independent validation.
