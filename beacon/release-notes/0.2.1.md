# Beacon .NET 0.2.1

本版本保留 `0.2.0` 的 MSI、DEB/RPM、跨平台 ZIP、统一管理命令与一键卸载能力，
并修复 Linux 原生包运行时可能受到同名宿主环境变量影响的问题。

## 修复

- `beacon-dotnet run` 不再把仅用于构建期的 `ARCHITECTURE` 环境变量传给探针启动脚本。
- DEB/RPM 的发布与验收流程改用专用的 `PACKAGE_ARCHITECTURE` 变量。
- 增加 `ARCHITECTURE=amd64` 场景的回归测试，确保探针使用已安装平台自动检测结果。

`0.2.0` 的公开 DEB x64 验收在安装和证明验证成功后，因工作流设置
`ARCHITECTURE=amd64` 而在启动阶段停止；其他 12 个平台验收均通过。按照不可覆盖
已发布制品的原则，本修复通过 `0.2.1` 发布。

## 发布内容

- Windows x64 MSI
- Debian/Ubuntu x64 与 ARM64 DEB
- RHEL/Rocky Linux x64 与 ARM64 RPM
- Linux glibc/musl、Windows、macOS 与 NuGet ZIP 归档
- SHA-256 校验清单、SPDX SBOM 与 GitHub artifact attestation

当前 MSI、DEB 与 RPM 尚未接入 Authenticode 或软件源签名，安装前应验证 GitHub
artifact attestation。DataKit 接收链路仍需独立端到端验收。
