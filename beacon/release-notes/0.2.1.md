# Beacon .NET 0.2.1

This release retains the MSI, DEB/RPM, cross-platform ZIP archives, unified
management command, and one-command uninstall capabilities from `0.2.0`. It
also fixes a host-environment-variable collision that could affect Linux native
packages at runtime.

## Fixes

- `beacon-dotnet run` no longer passes the build-time `ARCHITECTURE`
  environment variable to the profiler startup script.
- DEB/RPM release and validation workflows use the dedicated
  `PACKAGE_ARCHITECTURE` variable.
- A regression test covers `ARCHITECTURE=amd64` and verifies that the profiler
  uses automatic detection for the installed platform.

The public `0.2.0` DEB x64 validation successfully installed the package and
verified its attestation, but stopped during application startup because the
workflow set `ARCHITECTURE=amd64`. The other 12 post-release platform checks
passed. Because published assets are immutable, the fix is released as
`0.2.1`.

## Release Contents

- Windows x64 MSI
- Debian/Ubuntu x64 and ARM64 DEB packages
- RHEL/Rocky Linux x64 and ARM64 RPM packages
- Linux glibc/musl, Windows, macOS, and NuGet ZIP archives
- SHA-256 manifest, SPDX SBOM, and GitHub artifact attestations

The MSI, DEB, and RPM files are not yet covered by Authenticode or repository
signing. Verify the GitHub artifact attestation before installation. End-to-end
DataKit ingestion still requires independent validation.
