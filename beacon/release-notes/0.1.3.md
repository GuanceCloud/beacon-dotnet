# Beacon .NET 0.1.3

本版本保留完整跨平台资源，并修复 Unix 安装后的启动脚本执行权限。

## 发布内容

- Linux glibc x64、Linux glibc ARM64、Linux musl x64、Linux musl ARM64
- Windows x64/x86 组合归档
- macOS ARM64 归档
- 保留上游兼容包 ID 的 NuGet 聚合归档
- Shell 安装脚本与 PowerShell 安装模块
- SHA-256 校验清单、SPDX SBOM 和 GitHub artifact attestation

## 修复

GitHub Actions artifact 在作业间传递时不会保留 Unix 执行位。本版本在封装发布
ZIP 前恢复 `instrument.sh` 执行位，Shell 安装器解压后也会再次执行 `chmod +x`。

## 安装

```bash
curl -sSfL https://github.com/GuanceCloud/beacon-dotnet/releases/download/beacon-v0.1.3/otel-dotnet-auto-install.sh -o otel-dotnet-auto-install.sh
sh otel-dotnet-auto-install.sh
```

Windows PowerShell：

```powershell
Invoke-WebRequest https://github.com/GuanceCloud/beacon-dotnet/releases/download/beacon-v0.1.3/OpenTelemetry.DotNet.Auto.psm1 -OutFile OpenTelemetry.DotNet.Auto.psm1
Import-Module ./OpenTelemetry.DotNet.Auto.psm1
Install-OpenTelemetryCore
```

安装脚本默认使用 GitHub CLI 校验 artifact attestation。DataKit 接收链路仍需独立
端到端验收。
