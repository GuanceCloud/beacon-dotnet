# Beacon .NET 0.1.3

This release retains the complete cross-platform asset set and fixes the
executable permission of the Unix startup script after installation.

## Release Contents

- Linux glibc x64, Linux glibc ARM64, Linux musl x64, and Linux musl ARM64
- Combined Windows x64/x86 archive
- macOS ARM64 archive
- Aggregate NuGet archive retaining upstream-compatible package IDs
- Shell installer and PowerShell installation module
- SHA-256 manifest, SPDX SBOM, and GitHub artifact attestations

## Fix

GitHub Actions artifacts do not preserve Unix executable bits when transferred
between jobs. This release restores the executable bit on `instrument.sh`
before creating the Release ZIP, and the Shell installer defensively runs
`chmod +x` again after extraction.

## Installation

```bash
curl -sSfL https://github.com/beacon-observability/beacon-dotnet/releases/download/beacon-v0.1.3/otel-dotnet-auto-install.sh -o otel-dotnet-auto-install.sh
sh otel-dotnet-auto-install.sh
```

Windows PowerShell:

```powershell
Invoke-WebRequest https://github.com/beacon-observability/beacon-dotnet/releases/download/beacon-v0.1.3/OpenTelemetry.DotNet.Auto.psm1 -OutFile OpenTelemetry.DotNet.Auto.psm1
Import-Module ./OpenTelemetry.DotNet.Auto.psm1
Install-OpenTelemetryCore
```

By default, the installers use GitHub CLI to verify artifact attestations.
End-to-end DataKit ingestion still requires independent validation.
