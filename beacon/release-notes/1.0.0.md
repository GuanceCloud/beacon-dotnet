# Beacon .NET 1.0.0

## Highlights

- First stable release of Beacon .NET automatic instrumentation.
- One-command installation, runtime management, status checks, and complete
  uninstallation across supported platforms.
- Verified release artifacts with SHA-256 checksums, an SPDX SBOM, and GitHub
  artifact attestations.

## What's Included

- OpenTelemetry-based automatic instrumentation for .NET applications.
- Windows x64 MSI, Debian/Ubuntu x64 and ARM64 DEB packages, and RHEL/Rocky
  Linux x64 and ARM64 RPM packages.
- Linux glibc/musl, Windows, macOS, and NuGet ZIP archives.
- Shell and PowerShell standalone installers.
- The `beacon-dotnet` management command for native package installations.
- Standard `vX.Y.Z` Git tags and GitHub Releases.

## Management Commands

Native package installations provide a unified command for common operations:

```text
beacon-dotnet status
beacon-dotnet version
beacon-dotnet run <command>
beacon-dotnet uninstall
```

Standalone Shell and PowerShell installations include dedicated uninstall
scripts.

## Verification

Every downloadable artifact is included in `checksums.txt` and covered by a
GitHub artifact attestation. MSI, DEB, and RPM repository signing is not yet
available.
