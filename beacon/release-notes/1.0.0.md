## Highlights

Beacon .NET 1.0.0 is the first stable release of Beacon's OpenTelemetry-based
automatic instrumentation distribution for .NET.

## Changes

- Added native Windows MSI and Linux DEB/RPM packages for x64 and ARM64.
- Added the unified `beacon-dotnet status|version|run|uninstall` management
  command for native installations.
- Added complete uninstallation for native and standalone installations,
  including IIS and Windows Service cleanup on Windows.
- Added Shell and PowerShell installers and portable archives for Linux
  glibc/musl, Windows, macOS, and NuGet packages.
- Standardized product tags and GitHub Releases on the `vX.Y.Z` format.
- Added release metadata with the Beacon version, target platform, source
  commit, and pinned upstream provenance.
- Added SHA-256 checksums, an SPDX SBOM, and GitHub artifact attestations for
  release assets.
- Added post-release installation, runtime, and removal validation across
  Windows, Ubuntu, Rocky Linux, Alpine Linux, and macOS.

## Compatibility and Limitations

- Based on OpenTelemetry .NET Automatic Instrumentation `v1.17.0`.
- MSI, DEB, and RPM packages are not yet Authenticode-signed or distributed
  through signed package repositories; verify GitHub artifact attestations
  before installation.
- End-to-end DataKit ingestion is not part of the verified release scope.

See the [documentation](https://github.com/beacon-observability/beacon-dotnet/tree/v1.0.0/docs)
for installation, configuration, management, and troubleshooting.
