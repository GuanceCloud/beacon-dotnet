# Beacon .NET 0.1.1

This release adds cross-platform installation artifacts, supply-chain
materials, and post-release validation.

## Release Contents

- Linux glibc x64, Linux glibc ARM64, Linux musl x64, and Linux musl ARM64
- Combined Windows x64/x86 archive
- macOS ARM64 archive
- Aggregate NuGet archive retaining upstream-compatible package IDs
- Shell installer and PowerShell installation module
- SHA-256 manifest, SPDX SBOM, and GitHub build attestations

Every platform archive contains `BEACON-METADATA.json`, which identifies the
Beacon version, target platform, source commit, and pinned upstream provenance.

## Installation

Linux or macOS:

```bash
curl -sSfL https://github.com/beacon-observability/beacon-dotnet/releases/download/v0.1.1/otel-dotnet-auto-install.sh -o otel-dotnet-auto-install.sh
sh otel-dotnet-auto-install.sh
```

Windows PowerShell:

```powershell
Invoke-WebRequest https://github.com/beacon-observability/beacon-dotnet/releases/download/v0.1.1/OpenTelemetry.DotNet.Auto.psm1 -OutFile OpenTelemetry.DotNet.Auto.psm1
Import-Module ./OpenTelemetry.DotNet.Auto.psm1
Install-OpenTelemetryCore
```

By default, the installers use GitHub CLI to verify immutable Release assets
and build attestations.

## Validation Scope and Limitations

Build jobs continue to validate OTLP traces, metrics, and logs with real console
and ASP.NET Core applications. After publication, the Release assets are
downloaded from their public URLs to verify installers, archive attestations,
and metadata, and to run .NET 8 applications on Windows, macOS, and Linux
glibc/musl for x64 and ARM64.

This release does not claim Beacon-specific runtime enhancements or completed
end-to-end DataKit ingestion validation.
